# MyMenuAgent

A mobile-first PWA, doubling as the restaurant's own public website, that lets a single owner photograph their handwritten daily specials board, generate an on-brand styled image of it via AI, review/approve it, and publish it to the live site instantly with no redeploy.

## Confirmed stack (do not re-litigate)

- **Next.js 15 (App Router), TypeScript, Tailwind** — PWA + API routes + the restaurant's public marketing site, deployed on **Netlify** (superseded Vercel on 2026-07-14, owner's explicit call — see "Architecture pivot" below)
- **Supabase** — Postgres (RLS on `restaurant_id`), Auth, Storage (private buckets). Provider API keys are encrypted **app-side with AES-256-GCM** (`src/lib/providers/crypto.ts`), **not** Supabase Vault — this line said "Vault" until 2026-07-16; Vault was in the original plan and never used.
- **satori + resvg** for template PNG exports; **Netlify Scheduled Functions** for scheduled publishing

## Non-negotiable design rules

1. **Nothing restaurant-specific is ever hardcoded** — all identity, branding, and menu defaults come from the `restaurants` profile row. The public site and the Daily Specials image pipeline resolve branding from the profile at render/generation time.
2. **Every table carries `restaurant_id`** — this is the multi-tenant seam. Adding a restaurant must mean adding a row, never changing code.
3. **Publishing is a pointer flip** — immutable `published_snapshots` + `restaurants.live_snapshot_id`. Never introduce a publish path that requires a build or deploy.
4. **Provider API keys never reach the client** — encrypted at rest, decrypted only inside server handlers, never logged or echoed (display last-4 only). All AI calls go through the provider abstraction (capability interfaces + adapters), never direct vendor SDK calls from feature code.
5. **All surfaces read the same public API** (`GET /api/public/{slug}/menu` for Daily Specials, `GET /api/public/{slug}/main-menu` for the permanent menu): the site's own `/menu` page and homepage today, any future consumer (e.g. social publishing) later.
6. **Prices are integer cents** (`price_cents`) with a free-text `price_note` escape hatch.
